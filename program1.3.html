Program 03 - Copy array into second array

Problem Statement

Write a program to enter an array from user and copy the array into second array.

Logic

Use a for loop to copy each element of the first array into the corresponding position of the second array.

Source Code

#include <stdio.h>

void main()
{
	int num[5], a[5], i;

	printf("Enter 5 values: \n");
	
	for(i = 0; i <= 4; i++)
	{
		scanf("%d",&num[i]);
	}

	for(i = 0; i <= 4; i++)
	{
		a[i] = num[i];
	}

	printf("\nCopied successfully!\n");


	printf("2nd Array values are :\n");

	for(i = 0; i <= 4; i++)
	{
		printf("%d ",a[i]);
	}


}
