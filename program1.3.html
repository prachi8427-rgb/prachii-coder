Program 03 - Return an array from function

Problem Statement

Write a program to return an array from function.

Source Code

#include <stdio.h>
int * fun()
{
	static int a[]={10,20,30,40,50};
	return a;
}

void main()
{
	int *p, i;
	p = fun();

	printf("Array elements are:\n");

	for(i = 0; i < 5; i++)
	{
		printf("%d\n",*p);
		p++;
	}
}
