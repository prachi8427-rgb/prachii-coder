Program 03 - Convert String into Sentence Case

Problem Statement

Write a program to enter a string from user and convert into sentence case.

Logic

Convert the first character into uppercase and all remaining characters into lowercase.

Source Code

#include <stdio.h>

void main()
{
	char str[20];
	int i;

	printf("Enter a string: ");
	gets(str);

	if(str[0] >= 'a' && str[0] <= 'z')
	  str[0] = str[0] - 32;

	for(i = 1; str[i] != '\0'; i++)
	{
		if(str[i] >= 'A' && str[i] <= 'Z')
		str[i] = str[i] + 32;
	}

	printf("Sentence case: %s",str);
}
