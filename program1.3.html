Program 03 - Check Whether a Number is Prime or Not

Problem Statement

Write a program to enter a number from the user and check it is a prime number or not.

Logic

Check whether the number is divisible by any number from 2 to num-1. If no divisor is found, it is a prime number.

Source Code

#include <stdio.h>

void main()
{
	int num, i, prime = 1;

	printf("Enter a number: ");
	scanf("%d",&num);

	if(num <= 1)
	  prime = 0;
	else 
	{
		for(i = 2; i < num; i++)
		{
			if(num % i == 0)
			{
				prime = 0;
				break;
			}
		}
	}

	if(prime == 1)
	  printf("Number is Prime.");
	else 
      printf("Number is Not Prime.");
}
