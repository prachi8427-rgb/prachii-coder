Program 03 - Count the Digits of a Number

Problem Statement

Write a program to enter a number from the user and check that it is of 1 digit or 2 digit or 3 digit or 4 digit or 5 digit.

Logic

Use the if-else statements to count the digits based on the number's range.

Source Code

#include <stdio.h>

void main()
{
	unsigned int num;

	printf("Enter a number: ");
	scanf("%u",&num);

	if(num <= 9)
	  printf("1 Digit");
	else if(num <=99) 
      	  printf("2 Digit");
 	else if(num <=999) 
      	  printf("3 Digit");
    	else if(num <=9999) 
      	  printf("4 Digit");
   	else if(num <=99999) 
      	  printf("5 Digit");
    	else 
    	  printf("More than 5 digit.");
}
