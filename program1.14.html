Program 14 - Check Whether Character Exists

Problem Statement

Write a program to enter the string from user and enter a character , it is exist or not.

Logic

Compare the entered character with each character of the string. If a match is found, display that the character exists.

Source Code

#include <stdio.h>
#include <conio.h>

void main()
{
	char str[20], ch;
	int i, found = 0;

	printf("Enter a string: ");
	gets(str);
	printf("Enter a character: ");
	ch = getche();
	
	for(i = 0; str[i] != '\0'; i++)
	{
		if(str[i] == ch)
		{
			found = 1;
			break;
		}
	}

	if(found == 1)
	  printf("Character exists in string.");
	else
	  printf("Character doesn't exists in string.");
}
