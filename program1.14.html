Program 14 - Calculate Base Raised to Power

Problem Statement

Write a program to enter two numbers from users, one is base and second is power. Write the result.

Logic

Multiply the base by itself according to the given power using for loop.

Source Code

#include <stdio.h>

void main()
{
	int base, pow, i, result = 1;

	printf("Enter a base: ");
	scanf("%d",&base);

	printf("Enter a power: ");
	scanf("%d",&pow);

	if(pow >= 0)
	{
		for(i = 1; i <= pow; i++)
		{
			result = result * base;
		}
	  printf("Result = %d", result);
	}

	else
	  printf("Negative power is not supported.");
}
