Program 16 - Compare Two Characters

Problem Statement

Enter two characters from user and check both are same or not, if not same then find out difference between them.

Logic

Compare the characters and subtract their character values if they are different. 

#include <stdio.h>
#include <conio.h>

void main()
{
	char ch1,ch2;

	printf("Enter 1st character: ");
	ch1=getche();
	printf("\nEnter 2nd character: ");
	ch2=getche();
	
	if(ch1 == ch2)
	  printf("\nBoth are same");
	else
	{
	   if(ch1 > ch2)
	     printf("\nDifference = %d",ch1 - ch2);
	   else
	     printf("\nDifference = %d",ch2 - ch1);
	}
}
