Program 16 - Count Vowels in String

Problem Statement

Write a program to enter the string from user and count all vowels.

Logic

check each character of the string and increase the counter whenever a vowel is found.

Source Code

#include <stdio.h>

void main()
{
	char str[20];
	int i, count = 0;

	printf("Enter a string: ");
	gets(str);
	
	for(i = 0; str[i] != '\0'; i++)
	{
		if(str[i] == 'a' || str[i] == 'e' || str[i] == 'i' ||
		   str[i] == 'o' || str[i] == 'u' || str[i] == 'A' || 
		   str[i] == 'E' || str[i] == 'I' || str[i] == 'O' ||
		   str[i] == 'U')
		{
			count++;
		}
	}

	printf("Total vowels : %d",count);
}
