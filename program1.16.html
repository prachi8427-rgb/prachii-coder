Program 16 - Find the Sum From 0 to a Given Number

Problem Statement

Write a program to enter a number from user and print total from 0 to that number.

Logic

Use a for loop to add all number from 0 to the entered number.

Source Code

#include <stdio.h>

void main()
{
	int num, i, sum = 0;

	printf("Enter a number: ");
	scanf("%d",&num);

	for(i = 0; i <= num; i++)
	sum = sum + i;

	printf("Sum = %d",sum);
}
