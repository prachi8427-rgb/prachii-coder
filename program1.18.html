Program 18 - String Palindrome

Problem Statement

Write a program to enter the string from user and check string palindrome example (using reverse).

Logic

Compare the character from the beginning and end of the string. If all characters match, the string is a palindrome.

Source Code

#include <stdio.h>
#include <string.h>

void main()
{
	char str[20];
	int i, num, check = 1;

	printf("Enter a string: ");
	gets(str);

	num = strlen(str) - 1;

	for(i = 0; i < num; i++)
	{
		if(str[i] != str[num])
		{
			check = 0;
			break;
		}
		num--;
	}

	if(check == 1)
	  printf("String is palindrome.");
	else
	  printf("String is not palindrome.");
}
