Program 18 - Print the Range Between Two Numbers

Problem Statement

Write a program to enter two numbers from user and print range from first number to second number.

Logic

Use a for loop to print each number from first number to the second number.

Source Code

#include <stdio.h>

void main()
{
	int num1, num2, i;

	printf("Enter starting number: ");
	scanf("%d",&num1);
	printf("Enter ending number: ");
	scanf("%d",&num2);

	for(i = num1; i <= num2; i++)
	{
		printf("%d ",i);
	}
}
