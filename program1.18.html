Program 18 - Identify Character Type

Problem Statement

Enter a character from user and it is in upper case, lower case, special characters or numbers.

Logic

Compare the character with uppercase letters, lower case letters, and digits. 

#include <stdio.h>
#include <conio.h>

void main()
{
	char ch;

	printf("Enter a character: ");
	ch=getche();

	if(ch >= 'A' && ch <= 'Z')
	  printf("\nUppercase Character");
	else if(ch >= 'a' && ch <= 'z')
	  printf("\nLowercase Character");
	else if(ch >= '0' && ch <= '9')
	  printf("\nNumber");
	else
	  printf("\nSpecial character");
}
