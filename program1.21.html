Program 21 - Print Fibonacci Series up to 100

Problem Statement

Write a program to find out the Fibonacci series/ 1 to 100 (like 0 1 1 2 3 5 8 13………).

Logic

Start with 0 and 1. Use a while loop to print each term and calculate the next term by adding the previous two terms.

Source Code

#include <stdio.h>

void main()
{
	int a = 0, b = 1, c;

	while(a <= 100){
		printf("%d ",a);

		c = a + b;
		a = b;
		b = c;
	}
}
