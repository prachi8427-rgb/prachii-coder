Program 05 - Check Whether a Number Is Decimal

Problem Statement

Enter a number from the user and check it is a decimal number or not.

Logic

Compare the decimal number with its integer value to check whether it has a fractional part.

Source Code

#include <stdio.h>

void main()
{
	float num;
	int no;

	printf("Enter a number: ");
	scanf("%f",&num);

	no = num;

	if(num != no)
		printf("Decimal number");
	else 
	  printf("Integer number");
}
