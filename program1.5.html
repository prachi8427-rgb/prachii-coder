Program 05 - Arithmetic Operations On Two Numbers

Problem Statement

Write a program to enter 2 numbers from user add the number and show the answer , again take 2 number from user subtract the number display the answer ,again take 2 number from user multiply the number display the answer and ,again take 2 number from the user divide the number display the answer ,again take 2 number find the remainder and display the answer

Logic

Use arithmetic operators to calculate and display the results of two numbers.

Source Code

#include <stdio.h>

void main()
{
	int num1,num2;
	
	printf("Enter two numbers: ");
	scanf("%d %d",&num1,&num2);
	printf("Addition = %d\n\n",num1 + num2);

	printf("Enter two numbers: ");
	scanf("%d %d",&num1,&num2);
	printf("Subtraction = %d\n\n",num1 - num2);

	printf("Enter two numbers: ");
	scanf("%d %d",&num1,&num2);
	printf("Multiplication = %ld\n\n",num1 * num2);

	printf("Enter two numbers: ");
	scanf("%d %d",&num1,&num2);
	printf("Division = %d\n\n",num1 / num2);

	printf("Enter two numbers: ");
	scanf("%d %d",&num1,&num2);
	printf("Remainder = %d\n",num1 % num2);

}
