Program 05 - Print a Single Quote

Problem Statement

Write a C program to store a single quote in a variable and print the variable as output.

Logic

The printf() function with %c is used to display the stored character.

Source Code

#include <stdio.h>

void main()
{
	char quote='\'';
	printf("%c",quote);	
}

Output

C:\TURBOC3\BIN>TC

\'
