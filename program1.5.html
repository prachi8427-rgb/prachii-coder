Program 05 - Convert String into Toggle Case

Problem Statement

Write a program to enter a string from user and convert into toggle case.

Logic

Convert the uppercase letters into lowercase and lowercase letters into uppercase.

Source Code

#include <stdio.h>

void main()
{
	char str[20];
	int i;

	printf("Enter a string: ");
	gets(str);

	for(i = 0; str[i] != '\0'; i++)
	{
		if(str[i] >= 'a' && str[i] <= 'z')
		{
	        str[i] = str[i] - 32;
		}

		else if(str[i] >= 'A' && str[i] <= 'Z')
		{
			str[i] = str[i] + 32;
		}
	}

	printf("Toggle case: %s",str);
}
