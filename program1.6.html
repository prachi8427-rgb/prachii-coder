Program 06 - Find Length of String

Problem Statement

Write a program to enter a string from user and final length of the string.

Logic

Use strlen() function to count the total characters in the string.

Source Code

#include <stdio.h>
#include <string.h>

void main()
{
	char str[20];
	int num;

	printf("Enter a string: ");
	gets(str);

	num = strlen(str);

	printf("Length of string: %d",num);
}
