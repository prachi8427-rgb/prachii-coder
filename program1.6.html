Program 06 - Print the Last Digit of a Number

Problem Statement

Write a program to enter a number and print its last digit.

Logic

Use the modulus operator (%) with 10 to find the last digit of a number.

Source Code

#include <stdio.h>

void main()
{
	int num,last;
	
	printf("Enter any number: ");
	scanf("%d",&num);
	last = num % 10;
	printf("Last digit is = %d",last);
}
