Program 06 - Print Series from 1 to 1 Lakh

Problem Statement

Write a program to print a series 1 to 1 lakh.

Logic

Use a for loop to print numbers from 1 to 100000.

Source Code

#include <stdio.h>

void main()
{
	int i;

	for(i = 1; i <= 100000; i++)
	{
		printf("%d\n",i);
	}
}
