Program 06 - Print positive numbers from array

Problem Statement

Write a program to enter an array from user and print the number which is positive.

Logic

Use a for loop to check each array element. If an element is greater than zero then print it.

Source Code

#include <stdio.h>

void main()
{
	int num[5], i;

	printf("Enter 5 values: \n");
	
	for(i = 0; i <= 4; i++)
	{
		scanf("%d",&num[i]);
	}

	printf("Positive number are :\n");
	for(i = 0; i <= 4; i++)
	{
		if(num[i] > 0)
		{
			printf("%d ",num[i]);
		}
	}


}
