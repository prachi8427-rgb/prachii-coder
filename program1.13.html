Program 13 - Find Minimum value in array

Problem Statement

Write a program to find minimum values of array.

Logic

Assume the first array element is the minimum, then compare it with all other elements and update the minimum whenever a smaller value is found.

Source Code

#include <stdio.h>

void main()
{
	int num[5], i, mini;

	printf("Enter 5 values: \n");
	
	for(i = 0; i <= 4; i++)
	{
		scanf("%d",&num[i]);
	}

	mini = num[0];

	for(i = 1; i <= 4; i++)
	{
		if(num[i] < mini)
		  mini = num[i];
	}

	printf("Minimum value = %d",mini);
}
