Program 13 - Difference Between Characters of Two Strings

Problem Statement

Write a program to enter two string from user and print difference each character.

Logic

Subtract the ASCII value of each character of the second string from the corresponding character of the first string.

Source Code

#include <stdio.h>

void main()
{
	char str[20], str2[20];
	int i, diff;

	printf("Enter first string: ");
	gets(str);
	printf("Enter second string: ");
	gets(str2);

	for(i = 0; str[i] != '\0' && str2[i] != '\0'; i++)
	{
		printf("Difference of %c and %c = %d\n",str[i],str2[i],diff);
	}
}
