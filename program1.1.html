Program 01 - Check Positive, Negative or Zero

Problem Statement

Write a program to enter a number and check it is positive, negative or zero.

Logic

Use if-else statements to check whether the number is greater than, less than or equals to zero.

Source Code

#include <stdio.h>

void main()
{
	int num;

	printf("Enter a number: ");
	scanf("%d",&num);

	if(num > 0)
	  printf("Number is positive.");
	else if(num < 0)
    	  printf("Number is negative.");
        else 
    	  printf("Number is Zero.");
}
