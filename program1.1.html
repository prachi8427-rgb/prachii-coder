Program 01 - Display Array Values

Problem Statement

Write a program to enter an array from user and display all the value.

Logic

Use a for loop to input array elements and another for loop to display all the values.

Source Code

#include <stdio.h>

void main()
{
	int num[5], i;

	printf("Enter 5 values: \n");
	
	for(i = 0; i <= 4; i++)
	{
		scanf("%d",&num[i]);
	}

	printf("Array values are :\n");

	for(i = 0; i <= 4; i++)
	{
		printf("%d ",num[i]);
	}


}
