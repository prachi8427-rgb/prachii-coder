Program 01 - Example of Pre-Increament

Problem Statement

Write a program to show an example of pre-increament

Logic

Increase the value of a variable before printing it.

Source Code

#include <stdio.h>

void main()
{
	int a=5;
	
	printf("Value of a = %d",++a);
}

Output

C:\TURBOC3\BIN>TC
Value of a = 6
