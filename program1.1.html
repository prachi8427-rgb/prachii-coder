Program 01 - Print 11111 Pattern

Problem Statement

Write a program print the pattern on the screen i.e. ? 11111 11111 11111

Logic

Use two nested for loops. The outer loop controls the rows and the inner loop prints 1 five times in each row.

Source Code

#include <stdio.h>

void main()
{
	int i, j;

	for(i = 0; i <= 3; i++)
	{
		for(j = 0; j <= 5; j++)
		{
			printf("1");
		}
	  printf("\n");
	}
}
