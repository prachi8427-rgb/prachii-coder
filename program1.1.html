Program 01 - Find a Binary of a Number

Problem Statement

Write a program to enter a number from the user and find out the binary of that number.

Logic

Divide the number by 2 repeatedly and store the remainders.Print the remainder in reverse order.

Source Code

#include <stdio.h>

void main()
{
	int num, rem, binary = 0, place = 1;

	printf("Enter a number: ");
	scanf("%d",&num);

	if(num == 0)
	  printf("Binary = 0");
	else if(num > 0){
    	while(num > 0)
    	{
    		rem = num % 2;
    		binary = binary + rem * place;
    		place = place * 10;
    		num = num / 2;
      	}

    	  printf("Binary = %d",binary);
        }
        else 
    	  printf("Please enter a positive number.");
}
