Program 01 - Convert String into Uppercase

Problem Statement

Write a program to enter a string from user and convert in uppercase.

Logic

Check each character of the string. If it is a lower case then subtract 32 from its ASCII value to convert it into uppercase.

Source Code

#include <stdio.h>

void main()
{
	char str[20];
	int i;

	printf("Enter a string: ");
	gets(str);

	for(i = 0; str[i] != '\0'; i++)
	{
		if(str[i] >= 'a' && str[i] <= 'z')
		str[i] = str[i] - 32;
	}

	printf("Uppercase String : %s",str);
}
