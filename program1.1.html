Program 01 - Enter Four Numbers and Print them in a Matrix

Problem Statement

Write a program to enter the four number from user and print it into matrix.

Logic

Use nested loops to input four numbers and display them in matrix form.

Source Code

#include <stdio.h>

void main()
{
	int num[2][2], i, j;

	printf("Enter 4 values: \n");
	
	for(i = 0; i <= 1; i++)
	{
		for(j = 0; j<=1; j++)
		{
			scanf("%d",&num[i][j]);
		}
	}

	printf("Matrix is: \n");
	for(i = 0; i <= 1; i++)
	{
		for(j = 0; j<=1; j++)
		{
			printf("%d ",&num[i][j]);
		}
		printf("\n");
	}	

}
