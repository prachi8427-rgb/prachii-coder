Program 19 - Student Details Using String

Problem Statement

Write a program to Enter the data from user the data consist of roll no. ,name ,class , marks of 5 subjects.

Logic

Accept student details using character arrays and display all the entered information.

Source Code

#include <stdio.h>

void main()
{
	char name[20], class[10];
	int i, roll, m[5];

	printf("Roll no. : ");
	scanf("%d",&roll);
	fflush(stdin);
	printf("Enter Student name: ");
	gets(name);
	printf("Enter class: ");
	gets(class);
	printf("Enter marks of 5 subjects: \n");
	for(i = 0; i <= 4; i++)
	{
	printf("Subject %d: ", i + 1);
	scanf("%d",&m[i]);
	}

	printf("\nStudent Details\n");
	printf("Roll Number: %d\n",roll);
	printf("Name : %s\n",name);
	printf("Class : %s\n",class);
	for(i = 0; i <= 4; i++)
	{
	printf("Subjects %d marks: %d\n", i + 1, m[i]);
	}
}
