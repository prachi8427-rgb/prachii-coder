Program 19 - Check Leap Year

Problem Statement

Enter the year from user and check its leap year or not.

Logic

A year is a leap year if it is divisible by 400 or divisible by 4 but not by 100. 

#include <stdio.h>

void main()
{
	int num;

	printf("Enter a year: ");
	scanf("%d",&num);

	if(num % 400 == 0)
	  printf("Leap Year");
	else if(num % 100 == 0)
	  printf("Not a Leap Year");
	else if(num % 4 == 0)
	  printf("Leap Year");
	else
	  printf("Not a Leap Year");
}
