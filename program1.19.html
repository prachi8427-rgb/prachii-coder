Program 19 - Password Input up to 20 character

Problem Statement

Write a program to enter password from user maximum 20 digits / character press enter key if you want to exit.

Logic

Use a character array to store the password and a for loop to accept up to 20 characters.

Source Code

#include <stdio.h>

void main()
{
	int i;
	char pass[21];

	printf("Enter password : ");
	for(i = 0; i < 20; i++)
	{
		pass[i] = getche();

		if(pass[i] == 13)
		break;
	}

	pass[i] = '\0';
	printf("\nPassword: %s",pass);
}
