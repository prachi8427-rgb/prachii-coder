Program 08 - Concatenate Two Strings

Problem Statement

Write a program to enter a two string from user and concatenate the string.

Logic

Use strcat() function to join the second string at the end of the first string.

Source Code

#include <stdio.h>
#include <string.h>

void main()
{
	char str[20], str2[20];

	printf("Enter first string: ");
	gets(str);

	printf("Enter Second string: ");
	gets(str2);

	strcat(str,str2);

	printf("Concatenated string: %s",str);
}
