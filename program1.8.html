Program 08 - Find the Cube of a Number

Problem Statement

Write a program to enter a number and find its cube.

Logic

Multiply the number by itself three times to calculate its cube.

Source Code

#include <stdio.h>

void main()
{
	int num,res;
	
	printf("Enter a number: ");
	scanf("%d",&num);
	
	res = num * num * num;

	printf("Cube = %d",res);
}
