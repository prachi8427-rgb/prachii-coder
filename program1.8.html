Program 08 - Find Cube of a Number

Problem Statement

Make function for find out Cube a user entered number.

Source Code

#include <stdio.h>

int cube(int a)
{
	int result;
	
	result = a * a * a;

	return result;
}

void main()
{
	int num, res;

	printf("Enter a number: ");
	scanf("%d",&num);

	res = cube(num);

	printf("\nCube of %d = %d", num, res);

}
