Program 08 - Perform an Operation Based on Sign

Problem Statement

Enter a number from the user if the number is negative then square the number and if it is positive then increment the number 20 times.

Logic

Use if-else to check the sign of the number and perform the required operation. 

#include <stdio.h>

void main()
{
	int num,i;

	printf("Enter a number: ");
	scanf("%d",&num);

	if(num < 0)
	  printf("Square = %d", num * num);
	else{
	   for(i=0;i<20;i++)
	   num++;
	  printf("Number after 20 increments = %d",num);
	}
}

Output

Enter a number: 10
Number after 20 increments = 30
