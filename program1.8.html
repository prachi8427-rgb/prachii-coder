Program 08 - Print a Number 100 Times

Problem Statement

Write a program to Enter a number from the user and print that number 100 time.

Logic

Use a for loop to print the entered number 100 times.

Source Code

#include <stdio.h>

void main()
{
	int num, i;

	printf("Enter a number: ");
	scanf("%d",&num);

	for(i = 1; i <= 100; i++)
	{
		printf("%d\n",num);
	}
}
