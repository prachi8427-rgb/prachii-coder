Program 17 - Print Character at Given Index

Problem Statement

Write a program to enter the string from user and enter bound number and print character on that bound.

Logic

Check whether the entered index is within the string length. If valid, print the character at the index.

Source Code

#include <stdio.h>
#include <string.h>

void main()
{
	char str[20];
	int num;

	printf("Enter a string: ");
	gets(str);
	printf("Enter index number: ");
	scanf("%d",&num);

	if(num >= 0 && num < strlen(str))
	  printf("Character: %c",str[num]);
	else
	  printf("Out of bound!");
}
