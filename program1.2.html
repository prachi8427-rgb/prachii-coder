Program 02 - Add 10 numbers

Problem Statement

Write a program to enter 10 number from the user add the number and display the answer.

Source Code

#include <stdio.h>
void sum()
{
	int i, n, s=0;

	for(i = 1; i <= 10; i++)
	{
		printf("Enter a number: ");
		scanf("%d",&n);
		sum = sum + n;
	}

	printf("Sum = %d", sum);
}

void main()
{
	sum();
}
