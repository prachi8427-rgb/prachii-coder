Program 02 - Example of Post-Increament

Problem Statement

Write a program to show an example of post-increament

Logic

Print the current value of a variable first and then increase it by one.

Source Code

#include <stdio.h>

void main()
{
	int a=5;
	
	printf("Value of a before increment = %d\n",a++);
	printf("Value of a after increment = %d",a);
}

Output

C:\TURBOC3\BIN>TC

Value of a before increment = 5
Value of a after increment = 6
