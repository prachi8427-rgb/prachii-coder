Program 02 - Check Divisibility by Any Prime Number

Problem Statement

Write a program to enter a number from the user and check that the number is divisible by any prime number or not.

Logic

Check whether the number is divisible by any prime number from 2 up to the number - 1.

Source Code

#include <stdio.h>

void main()
{
	int num, i, j, prime, found = 0 ;

	printf("Enter a number: ");
	scanf("%d",&num);

	for(i = 2; i < num ; i++)
	{
		prime = 1;

		for(j = 2; j < i; j++)
		{
			if(i % j== 0)
			{
				prime = 0;
			    break;
			}
		}

	if(prime == 1 && num % i == 0)
		{ 
		  printf("Divisible by prime number : %d",i);
		  found = 1;
		}
	}

	if(found == 0)
	{
		printf("Not divisible by any smaller prime number.")
	}
}
