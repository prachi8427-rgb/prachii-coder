Program 02 - Find Transpose of a Matrix

Problem Statement

Write a program to enter the matrix from and transpose them.

Logic

Interchange the rows and columns of the matrix to find its transponse.

Source Code

#include <stdio.h>

void main()
{
	int num[2][2], i, j;

	printf("Enter 4 values: \n");
	
	for(i = 0; i <= 1; i++)
	{
		for(j = 0; j<=1; j++)
		{
			scanf("%d",&num[i][j]);
		}
	}

	printf("\nOriginal Matrix : \n");
	for(i = 0; i <= 1; i++)
	{
		for(j = 0; j<=1; j++)
		{
			printf("%d ",&num[i][j]);
		}
		printf("\n");
	}	

	printf("Transpose Matrix:\n");
	for(i = 0; i<=1; i++)
	{
		for(j = 0; j <= 1; j++)
		{
			printf("%d ",num[j][i]);
		}
	}

}
