Program 02 - Check Odd or Even

Problem Statement

Write a program to enter a number and check it is odd or even.

Logic

Use the modulus operator (%) to check the remainder when the number is divided by 2.

Source Code

#include <stdio.h>

void main()
{
	int num;

	printf("Enter a number: ");
	scanf("%d",&num);

	if(num % 2)
	  printf("Number is Odd.");
	else 
      	  printf("Number is Even.");
}
