Program 22 - Check Whether a Character is an Alphabet

Problem Statement

Write a program to enter a character from user and that character should be alphabet.

Logic

Check whether the entered character lies between A and Z or between a and b using if-else.

Source Code

#include <stdio.h>
#include <conio.h>

void main()
{
	char ch;

	printf("Enter a character: ");
	ch = getche();

	if(ch >= 'A' && ch <= 'Z' || ch >= 'a' && ch <= 'z')
	  printf("It is an Alphabet.");

	else
	  printf("It is not an Alphabet.");
}
