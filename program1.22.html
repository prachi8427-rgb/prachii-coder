Program 22 - Calculate Rectangle Area and Perimeter

Problem Statement

Write a program to calculate area and perimeter of rectangle.

Logic

Area = Length * breadth and perimeter = 2 * (length + breadth). 

#include <stdio.h>

void main()
{
    int l,b,area,pm;

    printf("Enter Length of rectangle: ");
    scanf("%d",&l);
    printf("Enter breadth of rectangle: ");
    scanf("%d",&b);

    area = l * b;
    pm = 2 * (l + b);    

    printf("Area = %d\n",area);
    printf("Perimeter = %d",pm);
}
