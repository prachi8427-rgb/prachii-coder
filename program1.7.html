Program 07 - Print Series from 1 to a Given Number

Problem Statement

Write a program to Enter a number from the user and print the series from 1 to that number.

Logic

Use a for loop to print all numbers from 1 up to the entered number.

Source Code

#include <stdio.h>

void main()
{
	int num, i;

	printf("Enter a number: ");
	scanf("%d",&num);

	for(i = 1; i <= num; i++)
	{
		printf("%d\n",i);
	}
}
