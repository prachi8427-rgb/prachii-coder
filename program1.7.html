Program 07 - Display C Program on Screen.

Problem Statement

Write a C program to Display the whole program on Output Screen.

Logic

Use printf() to display each line of the C program.

Source Code

#include <stdio.h>
#include <conio.h>
#include <dos.h>

void main()
{
	clrscr();
	printf("#include\n#include\n#include\n");
	printf("void main()\n");
	printf("{\n");
	printf("clrscr();\n");
	printf("printf(\"hello,welcome to c\");\n");
	printf("delay(5000);\n");
	printf("}");
	delay(5000);
}
