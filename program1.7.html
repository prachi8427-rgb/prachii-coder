Program 07 - Square all values of array

Problem Statement

Write a program to enter an array from user and square all the values of array.

Logic

Use a for loop to access each array element and multiply it by itself to calculate its square.

Source Code

#include <stdio.h>

void main()
{
	int num[5], i;

	printf("Enter 5 values: \n");
	
	for(i = 0; i <= 4; i++)
	{
	  scanf("%d",&num[i]);
	}

	printf("Square of array values are :\n");
	for(i = 0; i <= 4; i++)
	{
	  printf("%d ",num[i] * num[i]);
	}
}
