Program 07 - Print the Decimal Part of a Number

Problem Statement

Write a program to enter a number and print the digits after the decimal point.

Logic

Subtract the integer part of the number from the original number to get its decimal part.

Source Code

#include <stdio.h>

void main()
{
	float num;
	int a;
	
	printf("Enter a decimal number: ");
	scanf("%f",&num);
	a = num ;
	num = num - a;
	num = num*100;
	a=num;

	printf("Decimal part = %d",a);
}
