Program 07 - Check Whether a Character Is an Alphabet

Problem Statement

Enter a character from the user and check that it is an alphabet.

Logic

Check whether the character lies between A and Z or between a and z. 

#include <stdio.h>
#include <conio.h>

void main()
{
	char ch;

	printf("Enter a Character: ");
	
	ch=getche();

	if((ch >= 'A' && ch <= 'Z') || (ch >= 'a' && ch <= 'z'))
	printf("\nIt is an Alphabet");
	else 
	 printf("\nIt is not an Alphabet");
}
