Program 12 - Calculate Simple Interest

Problem Statement

Write a program to calculate interest using principal, rate and time.

Logic

Multiply principal by rate and time, then divide the result by 100.

Source Code

#include <stdio.h>
#include <conio.h>

void main()
{
	float p,r,t,si;
	
	printf("Enter principal amount: ");
	scanf("%f",&p);
	printf("Enter rate of interest: ");
	scanf("%f",&r);
	printf("Enter time in years: ");
	scanf("%f",&t);

	si = (p * r * t) / 100;

	printf("Simple Interest = %.2f",si);
}
