Program 12 - Find maximum value in array

Problem Statement

Write a program to find maximum values of array.

Logic

Assume the first array element is the maximum, then compare it with all other elements and update the maximum whenever a greater value is found.

Source Code

#include <stdio.h>

void main()
{
	int num[5], i, max;

	printf("Enter 5 values: \n");
	
	for(i = 0; i <= 4; i++)
	{
		scanf("%d",&num[i]);
	}

	max = num[0];

	for(i = 1; i <= 4; i++)
	{
		if(num[i] > max)
		  max = num[i];
	}

	printf("Maximum value = %d",max);
}
