Program 12 - Copy String in Reverse Order

Problem Statement

Write a program to enter the string from user and copy reverse order into another string.

Logic

Find the length of the string and copy its characters from the last position to the first position into another string.

Source Code

#include <stdio.h>
#include <string.h>

void main()
{
	char str[20], str2[20];
	int i, num;

	printf("Enter a string: ");
	gets(str);

	num = strlen(str) - 1;

	for(i = 0; num >= 0; i++)
	{
		str2[i] = str[num];
		num--;
	}

	str2[i] = '\0';

	printf("Original string: %s\n",str);
	printf("Copied string: %s",str2);
}
