Program 20 - Print Counting from 1 to 100 with Delay

Problem Statement

Write a program to print the counting 1 to 100 with one second delay.

Logic

Use a for loop to print number from 1 to 100 and delay(); to create a pause after each number.

Source Code

#include <stdio.h>
#include <dos.h>

void main()
{
	int i;

	for(i = 0; i < 20; i++)
	{
		printf("%d\n",i);
		delay(1000);
	}
}
