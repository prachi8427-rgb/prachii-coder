Program 15 - Print a One-Digit Number in Words

Problem Statement

Enter one digit number from user and print in words.

Logic

Use switch-case to print the word corresponding to the entered digit. 

#include <stdio.h>

void main()
{
	int num;

	printf("Enter a single digit number (0-9): ");
	scanf("%d",&num);
	
	switch(num)
	{ 
		case 0:
			printf("Zero");
			break;
		case 1:
			printf("One");
			break;
		case 2:
			printf("Two");
			break;
		case 3:
			printf("Three");
			break;
		case 4:
			printf("Four");
			break;
		case 5:
			printf("Five");
			break;
		case 6:
			printf("Six");
			break;
		case 7:
			printf("Seven");
			break;
		case 8:
			printf("Eight");
			break;
		case 9:
			printf("Nine");
			break;
		default:
		printf("Invalid input");
	}
}
