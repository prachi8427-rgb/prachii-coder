Program 15 - Find Position of Character

Problem Statement

Write a program to enter the string from user and enter a character if it is exist then print the bound number.

Logic

Compare the entered character with each character of the string and print its position when a match is found.

Source Code

#include <stdio.h>
#include <conio.h>

void main()
{
	char str[20], ch;
	int i, found = 0;

	printf("Enter a string: ");
	gets(str);
	printf("Enter a character: ");
	ch = getche();
	
	for(i = 0; str[i] != '\0'; i++)
	{
		if(str[i] == ch)
		{
			printf("Character found at position: %d", i + 1);
			found = 1;
			break;
		}
	}

	if(found == 0)
	  printf("Character not found.");
}
