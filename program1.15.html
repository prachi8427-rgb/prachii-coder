Program 15 - Print the First Digit of a Number

Problem Statement

Write a program to enter a number from user and print first digit of number.

Logic

Divide the number by 10 until only one digit remains.

Source Code

#include <stdio.h>

void main()
{
	int num;

	printf("Enter a number: ");
	scanf("%d",&num);

	while(num >= 10)
	{
		num = num / 10;
	}

	printf("First digit = %d",num);
}
