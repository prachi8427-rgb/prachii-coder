Program 04 - Print Your Name at the Center of the First Line

Problem Statement

Write a C program to print your name at the center of the first line.

Logic

Spaces are added before the name to position it approximately at the center of the first line.

Source Code

#include <stdio.h>

void main()
{
	printf("                   Prachi");	
}

Output

C:\TURBOC3\BIN>TC

                    Prachi
