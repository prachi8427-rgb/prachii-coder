Program 04 - Convert String into Title Case

Problem Statement

Write a program to enter a string from user and convert into title case.

Logic

Convert the first letter of each word into uppercase and all other letters into lowercase.

Source Code

#include <stdio.h>

void main()
{
	char str[20];
	int i;

	printf("Enter a string: ");
	gets(str);

	for(i = 0; str[i] != '\0'; i++)
	{
		if(i==0 || str[i-1] == ' ')
		{
			if(str[i] >= 'a' && str[i] <= 'z')
	          str[i] = str[i] - 32;
		}

		else
		{
			if(str[i] >= 'A' && str[i] <= 'Z')
		      str[i] = str[i] + 32;
		}
	}

	printf("Title case: %s",str);
}
