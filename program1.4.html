Program 04 - Example of Post-Decreament

Problem Statement

Write a program to show an example of post-decreament

Logic

Print the current value of a variable first and then decrease it by one.

Source Code

#include <stdio.h>

void main()
{
	int a=5;
	
	printf("Value of a before decrement = %d\n",a--);
	printf("Value of a after decrement = %d",a);
}

Output

C:\TURBOC3\BIN>TC
Value of a before decrement = 5
Value of a after decrement = 4
