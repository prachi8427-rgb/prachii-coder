Program 04 - Copy array into another array in reverse order

Problem Statement

Write a program to enter an array from user and copy it into another array in reverse order.

Logic

Use a for loop to copy the last element of the first array into the first position of the second array and continue in reverse order.

Source Code

#include <stdio.h>

void main()
{
	int num[5], a[5], i;

	printf("Enter 5 values: \n");
	
	for(i = 0; i <= 4; i++)
	{
		scanf("%d",&num[i]);
	}

	for(i = 0; i <= 4; i++)
	{
		a[i] = num[4-i];
	}

	printf("\nCopied in reverse order!\n");


	printf("2nd Array values are :\n");

	for(i = 0; i <= 4; i++)
	{
		printf("%d ",a[i]);
	}


}
