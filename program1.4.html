Program 04 - Print Each Digit on a Seprate Line

Problem Statement

Write a program to enter a number from the user and print all digit of the number in separate line.

Logic

Extract the last digit using the modulus operator and print it on a seperate line. Reverse the number first to display digits in their original order.

Source Code

#include <stdio.h>

void main()
{
	int num, rem, rev = 1;

	printf("Enter a number: ");
	scanf("%d",&num);

	if(num < 0)
	  num = -num;
	
	while(num > 0)
	{
		rem = num % 10;
		rev = rev * 10 + rem;
		num = num /10;
	}

	while(rev > 0)
	{
		rem = rev % 10;
		printf("%d\n", rem);
		rev = rev / 10;
	}
}
