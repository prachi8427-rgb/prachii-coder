Program 10 - Convert Lowercase to Uppercase

Problem Statement

Write a program to enter a lowercase alphabet and convert it into uppercase.

Logic

Subtract 32 from its ASCII value to convert it into uppercase.

Source Code

#include <stdio.h>
#include <conio.h>

void main()
{
	char ch;

	do{
		printf("Enter a lowercase alphabet: ");
		ch = getch();
		printf("\n");
	}	while(ch < 'a' || ch > 'z');
	ch = ch - 32;
	printf("Uppercase alphabet = %c",ch);
}
