Program 10 - Find the Greater of Two Numbers

Problem Statement

Enter two number from user and check which is the greater number and print the greater number.

Logic

Compare both numbers and print the greater number. 

#include <stdio.h>

void main()
{
	int a,b;

	printf("Enter first number: ");
	scanf("%d",&a);
	printf("Enter second number: ");
	scanf("%d",&b);

	if(a > b)
	  printf("Greater number = %d",a);
	else if(a < b)
	  printf("Greater number = %d",b");
	else 
	  printf("Both are equal");	
}
