Program 10 - Print Table of 4 up to 20

Problem Statement

Write a program print the table of 4 in the format given as below (till 20) 4*1=4 and so on.

Logic

Use a for loop from 1 to 20 and multiply each number by 4.

Source Code

#include <stdio.h>

void main()
{
	int i;

	for(i = 1; i <= 20; i++)
	{
		printf("4 * %d = %d\n", i, 4 * i);
	}
}
