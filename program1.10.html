Program 10 - Print ASCII Values of Two Characters

Problem Statement

Write a program to enter two character and print their ASCII values.

Logic

Read two characters using getche() and display their ASCII values.

Source Code

#include <stdio.h>
#include <conio.h>

void main()
{
	char ch1,ch2;
	
	clrscr();

	printf("Enter first character:");
	ch1=getche();
	printf("\nEnter Second character:");
	ch2=getche();
	printf("\nASCII value of first character = %d\n",ch1);
	printf("ASCII value of Second character = %d\n",ch2);
}

Output

Enter first character:A
Enter Second character:B
ASCII value of first character = 65
ASCII value of Second character = 66
