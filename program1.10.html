Program 10 - Search a value in array

Problem Statement

Write a program to enter 5 values of array from user, enter a value from user and search this value in array, if value is found then print “found” or not then print “not found”.

Logic

Use a for loop to compare the search value with each array element.

Source Code

#include <stdio.h>

void main()
{
	int num[5], find = 0, search, i;

	printf("Enter 5 values: \n");
	
	for(i = 0; i <= 4; i++)
	{
		scanf("%d",&num[i]);
	}

	printf("Enter value to search: ");
	scanf("%d",&search);

	
	for(i = 0; i <= 4; i++)
	{
		if(num[i] == search)
		{
			find = 1;
			break;
		}
	}
	if(find == 0)
	  printf("Not Found");
	else
	  printf("Found");
}
