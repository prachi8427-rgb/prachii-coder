Program 23 - Check Whether a Number is Armstrong

Problem Statement

Write a program to enter a number from user and check it is Armstrong number or not.

Logic

Extract each digit using modulo operator, calculate the sum of the cubes of the digits, and compare it with the original number.

Source Code

#include <stdio.h>

void main()
{
	int num, original, rem, sum = 0;

	printf("Enter a number: ");
	scanf("%d",&num);

	original = num;

	while(num > 0)
	{
		rem = num % 10;
		sum sum + (rem * rem * rem);
		num = num / 10;
	}

	if(original == sum)
	  printf("It is an Armstrong Number.");
	else
	  printf("It is not an Armstrong Number.");
}
