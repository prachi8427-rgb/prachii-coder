Program 09 - Copy String into Another String

Problem Statement

Write a program to enter a string from user and copy that string into another string.

Logic

Use strcpy() function to copy the first string into the second string.

Source Code

#include <stdio.h>
#include <string.h>

void main()
{
	char str[20], str2[20];

	printf("Enter a string: ");
	gets(str);

	strcpy(str2,str);

	printf("Original string: %s\n",str);
	printf("Copied string: %s",str2);
}
