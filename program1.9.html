Program 09 - Check Positive or Negtive Number

Problem Statement

Enter the number from the user it the number is negative or positive and find out of that number.

Logic

Use if-else statement to check whether the number is positive, negative, or zero. 

#include <stdio.h>

void main()
{
	int num;

	printf("Enter a number: ");
	scanf("%d",&num);

	if(num > 0)
	  printf("Number is Positive");
	else if(num < 0)
	  printf("Number is Negative");
	else 
	  printf("Number is Zero");	
}
