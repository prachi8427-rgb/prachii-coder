Program 09 - Round Off a Decimal Number

Problem Statement

Write a program to enter a decimal number and round it off to the nearest integer.

Logic

Add 0.5 to the positive decimal number and convert it into a integer.

Source Code

#include <stdio.h>

void main()
{
	float num;
	int round;
	
	printf("Enter a decimal number: ");
	scanf("%f",&num);
	
	round = (int)(num + 0.5);

	printf("Rounded number = %d",round);
}
