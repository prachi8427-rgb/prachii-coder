Program 09 - Display Password as Stars

Problem Statement

Write a program to enter a password and display it as stars.

Logic

Read password characters using getch() and print a star for each character.

Source Code

#include <stdio.h>
#include <conio.h>

void main()
{
	char pass[6];
	int i=0;

	clrscr();

	printf("Enter 6 digit Password:");
	for(i=0; i<=5; i++){
		pass[i]=getch();
		printf("*");
	}
}
