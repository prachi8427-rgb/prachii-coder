Program 09 - Print All Odd Numbers from 1 to 100

Problem Statement

Write a program print all the odd number between 1 to 100.

Logic

Use a for loop and print numbers that are not divisible by 2.

Source Code

#include <stdio.h>

void main()
{
	int i;

	for(i = 1; i <= 100; i++)
	{
		if(i % 2 != 0)
		printf("%d\n",i);
	}
}
