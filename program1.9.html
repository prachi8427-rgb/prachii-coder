Program 09 - Add all 5 array values

Problem Statement

Write a program to enter 5 values of array from user and add all values.

Logic

Use a for loop to input 5 array values and another loop to add all element into the sum variable.

Source Code

#include <stdio.h>

void main()
{
	int num[5], sum = 0, i;

	printf("Enter 5 values: \n");
	
	for(i = 0; i <= 4; i++)
	{
		scanf("%d",&num[i]);
	}

	
	for(i = 0; i <= 4; i++)
	{
		sum = sum + num[i];
	}

	printf("Sum of array values = %d",sum);
}
