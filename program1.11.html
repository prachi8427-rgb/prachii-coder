Program 11 - Calculate Average Marks

Problem Statement

Write a program to enter marks of three subjects and calculate their average.

Logic

Add the marks of subjects and calculate their average.

Source Code

#include <stdio.h>
#include <conio.h>

void main()
{
	int num1,num2,num3;
	float average;

	printf("Enter first student marks: ");
	scanf("%d",&num1);
	printf("Enter second student marks: ");
	scanf("%d",&num2);
	printf("Enter third student marks: ");
	scanf("%d",&num3);

	average = (num1 + num2 + num3) / 3.0;

	printf("Average marks = %.2f",average);
}
