Program 11 - Print ASCII Characters from 0 to 127

Problem Statement

Write a program to Print all ASCII character 0 to 127

Logic

Use a for loop to print each ASCII value and its corresponding character.

Source Code

#include <stdio.h>
#include <conio.h>

void main()
{
	int i;
	
	clrscr();

	for(i=0; i<=127; i++){
