Program 11 - Sort array in ascending order

Problem Statement

Write a program to enter five values of array and sort in ascending order.

Logic

Use nested for loop to compare array elements and swap them whenever the previous element is greater than the next element.

Source Code

#include <stdio.h>

void main()
{
	int num[5], i, j, temp;

	printf("Enter 5 values: \n");
	
	for(i = 0; i <= 4; i++)
	{
		scanf("%d",&num[i]);
	}

	for(i = 0; i <= 3; i++)
	{
		for(j = 0; j >= 3-i; j++)
		{
			if(num[j] > num[j+1])
			{
				temp = num[j];
				num[j] = num[j+1];
				num[j+1] = temp;
			}
		}
	}

	printf("Array in ascending order:\n");
	for(i = 0; i<= 4; i++)
	{
		printf("%d ", num[i]);
	}
}
