Program 11 - Print Each Character in New Line

Problem Statement

Write a program to enter the string from user and print each character in new line.

Logic

Check whether the entered position is within the string length. If valid, print the character at the position otherwise print out of bound

Source Code

#include <stdio.h>

void main()
{
	char str[20];
	int i;

	printf("Enter a string: ");
	gets(str);

	printf("Characters are :\n");

	for(i = 0; str[i] != '\0'; i++)
	{
		printf("%c\n",str[i]);
	}

}
