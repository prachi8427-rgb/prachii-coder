Program 11 - Check Divisibility by 4

Problem Statement

Enter a number from user and check it is divisible by 4 or not.

Logic

Use modulus operator (%) to check whether the remainder is zero. 

#include <stdio.h>

void main()
{
	int num;

	printf("Enter a number: ");
	scanf("%d",&num);
	
	if(num % 4)
	  printf("Number is not divisible by 4");
	else 
	  printf("Number is divisible by 4");
}
