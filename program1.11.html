Program 11 - Reverse a Number

Problem Statement

Write a program to enter the number from user and reverse the number.

Logic

Extract the last digit using modulus, add it to the reversed number, and remove the last digit using division.

Source Code

#include <stdio.h>

void main()
{
	int num, rem, rev = 0;

	printf("Enter a number: ");
	scanf("%d",&num);

	while(num != 0)
	{
		rem = num % 10;
		rev = rev * 10 + rem;
		num = num / 10;
	}

	printf("Reverse = %d",rev);
}
